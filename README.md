# USNStart Coworking Space Website

## Project Overview

This project is a web solution developed for the **fictional** **USNStart Coworking Space**, created as part of the *Practical Project Work (PRO1000)* course (Spring 2024).

The goal was to design and deliver a functional website that presents the coworking concept, supports its target audience, and meets stakeholder requirements through an iterative development process.

---

## Background

USNStart is a **fictional coworking concept** created for a university project at the University of South-Eastern Norway (USN), located at the Bø campus.

The project explores the transformation of three former laboratory spaces into a modern coworking environment for:

- Students  
- Startups  
- Local businesses  

The focus was to design and develop a realistic website that communicates the concept, supports user needs, and reflects a potential real-world implementation.

This repository contains the resulting web solution.

---

## Features

- Responsive website design  
- Informational pages about the coworking space  
- User-focused layout and navigation  
- Visual assets and prototypes  
- Privacy policy integration (GDPR compliant)

## Development Process

The project followed an **agile methodology** with iterative development cycles:

- Requirement gathering from stakeholders  
- User story-driven development  
- Prototyping (low- and high-fidelity)  
- Sprint-based workflow  
- Continuous testing and validation
